# AI_autoscalar
Reinforcement Learning based cluster node scaling based on dummy metrics metrics generated.
## Abstract
In modern cloud-native environments, microservices-based architectures demand efficient and intelligent resource management to ensure optimal performance, scalability, and cost effectiveness. Traditional static or rule-based resource allocation strategies often fall short in adapting to dynamic and unpredictable workloads. This project proposes an AI-driven control theory approach for dynamic resource allocation in microservices. The system leverages real-time monitoring of key performance indicators such as CPU utilization, memory usage, and response times, combined with machine learning techniques to predict future resource demands. A control-theoretic feedback loop—integrated with reinforcement learning or adaptive controllers—adjusts the allocation of resources proactively. This allows the system to automatically scale services up or down, minimizing latency and resource wastage while maintaining service-level objectives (SLOs).
